## Deployment

This project is deployed using **GitHub Pages**. To deploy:

1. Create a new GitHub repository (e.g., `dsa-learning`)
2. Push this folder to the repository:
   ```bash
   git init
   git add .
   git commit -m "Initial commit - DSA Learning Hub"
   git branch -M main
   git remote add origin https://github.com/YOUR_USERNAME/dsa-learning.git
   git push -u origin main
   ```
3. Go to **Settings → Pages** in your GitHub repo
4. Set Source to **Deploy from a branch** → `main` → `/ (root)`
5. Your site will be live at `https://YOUR_USERNAME.github.io/dsa-learning/`
