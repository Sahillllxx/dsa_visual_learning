Intuition — Think Like Striver
🎙 STRIVER SAYS
Okay so naive approach? Count 0s, 1s, 2s and fill back — that's two passes. But can we do it in one pass? Yes! And that's where the Dutch National Flag algorithm comes in. This was given by Edsger Dijkstra. The Dutch flag has three colours — red, white, blue — and we're sorting three types of elements. Get it? 😄

We'll use three pointers: low, mid, and high. Think of the array as four regions:
low
0s go here ←
mid
current element
high
2s go here →
🎙 INVARIANT (the rule we maintain)
✅ arr[0..low-1] → all 0s (sorted)
✅ arr[low..mid-1] → all 1s (sorted)
❓ arr[mid..high] → UNKNOWN (we process this)
✅ arr[high+1..n-1] → all 2s (sorted)
3
The 3 Cases — This is the HEART of the Algorithm
CASE 1 — arr[mid] == 0 (Red / 0)
If current element is 0, it belongs at the beginning!
→ Swap arr[mid] with arr[low]
→ Increment both low++ and mid++
Why mid++? Because after swap, arr[mid-1] is 0 (placed correctly) and arr[mid] was from the sorted 1s zone — safe!
CASE 2 — arr[mid] == 1 (White / 1)
If current element is 1, it's already in the right zone!
→ Just do mid++
The 1s zone expands to the right naturally.
CASE 3 — arr[mid] == 2 (Blue / 2)
If current element is 2, it belongs at the end!
→ Swap arr[mid] with arr[high]
→ Decrement high--
→ DO NOT increment mid!
Why? Because what came from arr[high] is unknown — we haven't processed it yet!

The Code — Clean & Simple
🎙 STRIVER SAYS
Dekho bhaiya, code kitna clean hai! Just 3 pointers, one while loop, three conditions. That's it. This is the beauty of this algorithm! 
void sortColors(vector<int>& arr) {
    int low  = 0;                 // boundary for 0s
    int mid  = 0;                 // current element
    int high = arr.size() - 1;    // boundary for 2s

    while (mid <= high) {
        if (arr[mid] == 0) {
            // 0 belongs at the front → swap with low
            swap(arr[low], arr[mid]);
            low++;
            mid++;
        }
        else if (arr[mid] == 1) {
            // 1 is already in correct zone → just move mid
            mid++;
        }
        else {
            // 2 belongs at the end → swap with high
            swap(arr[mid], arr[high]);
            high--;
            // don't increment mid! element from high is unknown
        }
    }
}

🔑 Key Insight (Striver's Golden Trick):
The loop runs while mid ≤ high. When mid crosses high, the unknown region is empty — everything is sorted. The reason we don't do mid++ when arr[mid]==2 is that the element coming from arr[high] after the swap is still unknown — we must re-examine it!
