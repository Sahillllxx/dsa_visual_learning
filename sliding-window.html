01
What is Sliding Window?
🎙
STRIVER SAYS
Okay so bhaiya, sliding window is a technique, not a data structure. Whenever you have an array or string and you're working on a contiguous subarray or substring — that's your signal. Instead of using nested loops which give you O(n²), you use a window that slides through the array and that gets you down to O(n). That's the whole magic! 🔥
💡
THE REAL WORLD ANALOGY
Socho ek train hai. Aur ek window hai usme. Jab train chalti hai, window move karti hai — but the window ka size same rehta hai. You only see what's inside the window at any point. That's exactly what we do with arrays — we maintain a window [left ... right] and slide it forward! 🚂
❌ Brute Force: O(n²) — Nested loops
✅ Sliding Window: O(n) — Single pass
02
Two Types — You MUST Know Both
🎙
STRIVER SAYS
Bhaiya yeh bahut important hai. Sliding window ke do types hote hain. Agar tum dono types samajh lo, 90% sliding window problems tum khud solve kar loge. Trust me!
TYPE 1
Fixed Size Window
Window size k is given. You maintain a window of exactly k elements and slide it one step at a time.

Signal: "...of size k", "...k consecutive elements"

Example: Max sum of subarray of size k
TYPE 2
Variable Size Window
Window size changes dynamically. You expand right pointer and shrink left pointer based on a condition.

Signal: "longest/shortest subarray with condition X"

Example: Longest substring without repeating chars

int maxSumSubarray(vector<int>& arr, int k) {
    int n = arr.size();
    int windowSum = 0, maxSum = INT_MIN;

    // Step 1: Build the first window
    for (int i = 0; i < k; i++)
        windowSum += arr[i];
    maxSum = windowSum;

    // Step 2: Slide the window — add right, remove left
    for (int i = k; i < n; i++) {
        windowSum += arr[i];
        windowSum -= arr[i - k];
        maxSum = max(maxSum, windowSum);
    }
    return maxSum;
}

int maxSumSubarray(int[] arr, int k) {
    int n = arr.length;
    int windowSum = 0, maxSum = Integer.MIN_VALUE;
    for (int i = 0; i < k; i++)
        windowSum += arr[i];
    maxSum = windowSum;
    for (int i = k; i < n; i++) {
        windowSum += arr[i] - arr[i - k];
        maxSum = Math.max(maxSum, windowSum);
    }
    return maxSum;
}

def maxSumSubarray(arr, k):
    window_sum = sum(arr[:k])
    max_sum = window_sum
    for i in range(k, len(arr)):
        window_sum += arr[i] - arr[i - k]
        max_sum = max(max_sum, window_sum)
    return max_sum

int longestSubarrayWithSumK(vector<int>& arr, int target) {
    int left = 0, right = 0;
    int windowSum = 0, maxLen = 0;

    while (right < arr.size()) {
        windowSum += arr[right]; // expand window

        // shrink from left if condition violated
        while (windowSum > target) {
            windowSum -= arr[left];
            left++;
        }

        // valid window — update answer
        maxLen = max(maxLen, right - left + 1);
        right++;
    }
    return maxLen;
}

int longestSubarrayWithSumK(int[] arr, int target) {
    int left = 0, right = 0;
    int windowSum = 0, maxLen = 0;
    while (right < arr.length) {
        windowSum += arr[right];
        while (windowSum > target)
            windowSum -= arr[left++];
        maxLen = Math.max(maxLen, right - left + 1);
        right++;
    }
    return maxLen;
}

def longestSubarrayWithSumK(arr, target):
    left = 0
    window_sum = 0
    max_len = 0
    for right in range(len(arr)):
        window_sum += arr[right]
        while window_sum > target:
            window_sum -= arr[left]
            left += 1
        max_len = max(max_len, right - left + 1)
    return max_len

The Master Template — Memorise This!
🎙
STRIVER SAYS
Bhaiya, yeh template yaad kar lo. Sab sliding window problems isi se solve hoti hain. Bas condition change hogi, structure same rehega. Ye mera guarantee hai! 😄
VARIABLE WINDOW MASTER TEMPLATE
int left = 0, right = 0;
// initialize your window state (sum, map, freq etc.)

while (right < n) {
    // 1. EXPAND — add arr[right] to window

    // 2. SHRINK — while window is INVALID, remove arr[left], left++
    while (!isValid(window)) {
        remove(arr[left]);
        left++;
    }

    // 3. RECORD — window is now valid, update answer
    ans = max(ans, right - left + 1);
    right++;
}
🔑 Striver's Key Insight:
The right pointer always moves forward — it never goes back. That's why we get O(n). Each element is added once (by right) and removed at most once (by left). So total operations = 2n = O(n). Beautiful, right? 🔥
