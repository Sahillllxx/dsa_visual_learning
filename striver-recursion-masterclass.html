What is Recursion?

Recursion is when a function calls itself until a specified condition (base case) is met.

Think of it like this — you're standing in front of a mirror with another mirror behind you. You see infinite reflections. Each reflection is a "call" and the moment you remove one mirror, the reflections stop. That's your base case.

📌 Key Definition

A function that calls itself repeatedly until a base condition is met is called a recursive function.

void f() {
    // Base condition (MUST have one)
    if (condition) return;
    
    // Some work
    
    f(); // Function calls itself
}
"If there's no base case, the function will call itself infinitely → Stack Overflow! Always think about WHERE to stop first."

How Recursion Works - The Call Stack

Every time a function is called, it's pushed onto the call stack. When it returns, it's popped off. This is the most crucial concept!

main() calls f(3) → f(3) calls f(2) → f(2) calls f(1) → f(1) hits base case, returns ← f(2) resumes, returns ← f(3) resumes, returns ← main() continues

🧠 Stack Memory Visualization

Each recursive call creates a new stack frame with its own local variables. The stack grows until base case is hit, then unwinds.

Frame 3 (top)f(1)Base case → returns
Frame 2f(2)Waiting for f(1)
Frame 1f(3)Waiting for f(2)
Frame 0 (bottom)main()Waiting for f(3)
"Always dry run with the stack. Draw it on paper. Once you SEE how the stack builds and unwinds, recursion clicks forever."

Base Case & Stack Overflow

What if there's no base case?

void infinite() {
    cout << "Hello";
    infinite(); // Never stops!
}
// Result: SEGMENTATION FAULT (Stack Overflow)

The stack has limited memory. If you keep pushing frames without popping, it overflows. This is called Stack Overflow or Segmentation Fault.

✅ Rules for Base Case

  • Every recursive function MUST have a base case
  • Base case should be reachable (function must progress toward it)
  • Think of the smallest/simplest version of the problem

Print Name N Times

Problem: Print your name N times using recursion (no loops!).

"This is the simplest recursion problem. If you can't do this, you can't do anything ahead. Master this first!" 
void printName(int i, int n) {
    // Base case: if i exceeds n, stop
    if (i > n) return;
    
    cout << "Striver" << endl;
    printName(i + 1, n); // Move toward base case
}

// Call: printName(1, 5) → prints "Striver" 5 times
printName(1, 5) → prints "Striver", calls printName(2, 5) printName(2, 5) → prints "Striver", calls printName(3, 5) printName(3, 5) → prints "Striver", calls printName(4, 5) printName(4, 5) → prints "Striver", calls printName(5, 5) printName(5, 5) → prints "Striver", calls printName(6, 5) printName(6, 5) → 6 > 5 → RETURN

Print N to 1

Problem: Print numbers from N to 1 using recursion.

Approach 1: Direct (Print before call)

void printNTo1(int n) {
    if (n < 1) return;
    
    cout << n << endl;   // Print BEFORE recursive call
    printNTo1(n - 1);
}

// Call: printNTo1(5) → 5 4 3 2 1

Approach 2: Using Backtracking (Print AFTER call)

void printNTo1_BT(int i, int n) {
    if (i > n) return;
    
    printNTo1_BT(i + 1, n); // Call FIRST
    cout << i << endl;       // Print while coming back (backtracking)
}

// Call: printNTo1_BT(1, 5) → 5 4 3 2 1
"This is VERY important! Where you place the print — before or after the recursive call — completely changes the output. This is the foundation of backtracking!"

Sum of First N Numbers

Two approaches: Parameterised and Functional recursion.

Approach 1: Parameterised (carry answer in parameter)

void sumParam(int i, int sum) {
    if (i < 1) {
        cout << sum;
        return;
    }
    sumParam(i - 1, sum + i);
}
// sumParam(5, 0) → prints 15

Approach 2: Functional (return the answer)

int sumFunc(int n) {
    if (n == 0) return 0;
    return n + sumFunc(n - 1);
}
// sumFunc(5) → 5 + 4 + 3 + 2 + 1 + 0 = 15
"Parameterised = you carry the answer along. Functional = the function itself returns the answer. Both are valid, but functional is more elegant for most problems."

Factorial of N

n! = n × (n-1) × (n-2) × ... × 1, where 0! = 1
int factorial(int n) {
    if (n == 0) return 1; // Base case: 0! = 1
    return n * factorial(n - 1);
}

// factorial(5) = 5 * factorial(4)
//              = 5 * 4 * factorial(3)
//              = 5 * 4 * 3 * factorial(2)
//              = 5 * 4 * 3 * 2 * factorial(1)
//              = 5 * 4 * 3 * 2 * 1 * factorial(0)
//              = 5 * 4 * 3 * 2 * 1 * 1
//              = 120

Reverse an Array

Problem: Reverse an array using recursion.

Approach: Two Pointer (Swap from both ends)

void reverseArray(int arr[], int l, int r) {
    if (l >= r) return; // Base case: pointers crossed
    
    swap(arr[l], arr[r]);
    reverseArray(arr, l + 1, r - 1);
}

// [1, 2, 3, 4, 5] → swap(1,5) → [5, 2, 3, 4, 1]
//                  → swap(2,4) → [5, 4, 3, 2, 1]
//                  → l >= r    → STOP ✅

Approach: Single Variable

void reverseArray(int arr[], int i, int n) {
    if (i >= n / 2) return;
    
    swap(arr[i], arr[n - i - 1]);
    reverseArray(arr, i + 1, n);
}

Check if String is Palindrome

Same logic as reverse! Compare characters from both ends.

bool isPalindrome(string s, int l, int r) {
    if (l >= r) return true; // All matched!
    
    if (s[l] != s[r]) return false; // Mismatch found
    
    return isPalindrome(s, l + 1, r - 1);
}

// isPalindrome("madam", 0, 4) → m==m ✓ → a==a ✓ → l>=r → true

Fibonacci Number (Multiple Recursion Calls)

This is where recursion gets interesting — a function calling itself TWICE!

fib(n) = fib(n-1) + fib(n-2), where fib(0)=0, fib(1)=1
int fib(int n) {
    if (n <= 1) return n;
    return fib(n - 1) + fib(n - 2);
}
// Time: O(2^n) — exponential! (can optimize with DP later)
fib(5) / \ fib(4) fib(3) / \ / \ fib(3) fib(2) fib(2) fib(1) / \ / \ / \ | f(2) f(1) f(1) f(0) f(1) f(0) 1 / \ | | | | | f(1) f(0) 1 1 0 1 0 | | 1 0 Result: 5
"This is O(2^n) — very slow! But understand this pattern first. When we do Dynamic Programming later, we'll optimize this to O(n). Foundation first, optimization later!"

Print All Subsequences

A subsequence is a contiguous or non-contiguous sequence that follows the order of the original array.

📌 Key Insight: Take / Not-Take Pattern

At every index, you have TWO choices:

  • Take the current element (include it)
  • Not Take the current element (exclude it)

This gives 2^n total subsequences.

void printSubseq(int ind, vector<int>& ds, int arr[], int n) {
    if (ind == n) {
        // Print the subsequence
        for (auto it : ds) cout << it << " ";
        cout << endl;
        return;
    }
    
    // TAKE the element
    ds.push_back(arr[ind]);
    printSubseq(ind + 1, ds, arr, n);
    
    // NOT TAKE (backtrack)
    ds.pop_back();
    printSubseq(ind + 1, ds, arr, n);
}
arr = [3, 1, 2] f(0, []) / \ TAKE 3 NOT TAKE 3 f(1, [3]) f(1, []) / \ / \ TAKE 1 NOT 1 TAKE 1 NOT 1 f(2,[3,1]) f(2,[3]) f(2,[1]) f(2,[]) / \ / \ / \ / \ T2 NT2 T2 NT2 T2 NT2 T2 NT2 Results: [3,1,2] [3,1] [3,2] [3] [1,2] [1] [2] []
"Take / Not-Take is the MOST important pattern in recursion. Subsequences, subsets, combination sum — everything uses this. Master this and you've mastered 70% of recursion problems!"

Subsequences with Sum = K

Print all subsequences whose elements sum up to K.

void subseqSum(int ind, vector<int>& ds, int s, int arr[], int n, int k) {
    if (ind == n) {
        if (s == k) {
            // Print subsequence
            for(auto it : ds) cout << it << " ";
            cout << endl;
        }
        return;
    }
    
    // Take
    ds.push_back(arr[ind]);
    s += arr[ind];
    subseqSum(ind + 1, ds, s, arr, n, k);
    
    // Not Take (backtrack)
    ds.pop_back();
    s -= arr[ind];
    subseqSum(ind + 1, ds, s, arr, n, k);
}

Count Subsequences with Sum = K

Instead of printing, just count them. Return 1 if condition met, 0 otherwise.

int countSubseq(int ind, int s, int arr[], int n, int k) {
    if (ind == n) {
        if (s == k) return 1;
        return 0;
    }
    
    // Take
    s += arr[ind];
    int left = countSubseq(ind + 1, s, arr, n, k);
    
    // Not Take
    s -= arr[ind];
    int right = countSubseq(ind + 1, s, arr, n, k);
    
    return left + right;
}
"When the problem says 'count', don't store — just return 1 or 0 and ADD the left and right recursive calls. This is a pattern you'll see in DP too!"

Combination Sum

Find all unique combinations where chosen numbers sum to target. You can use the same element unlimited times.

void combSum(int ind, int target, vector<int>& ds, 
             vector<int>& arr, vector<vector<int>>& ans) {
    if (ind == arr.size()) {
        if (target == 0) ans.push_back(ds);
        return;
    }
    
    // Pick (stay at same index — can pick again!)
    if (arr[ind] <= target) {
        ds.push_back(arr[ind]);
        combSum(ind, target - arr[ind], ds, arr, ans);
        ds.pop_back();
    }
    
    // Not pick (move to next index)
    combSum(ind + 1, target, ds, arr, ans);
}

🔑 Key Difference

When you pick, you stay at the same index (ind, not ind+1) because you can pick the same element again. When you don't pick, you move forward.

Subset Sum (Print All Subset Sums)

void subsetSum(int ind, int sum, vector<int>& arr, int n, vector<int>& sumList) {
    if (ind == n) {
        sumList.push_back(sum);
        return;
    }
    
    // Take
    subsetSum(ind + 1, sum + arr[ind], arr, n, sumList);
    
    // Not Take
    subsetSum(ind + 1, sum, arr, n, sumList);
}
// Sort sumList to get all subset sums in order

Print All Permutations

Given an array, print all possible arrangements (order matters!).

Approach 1: Using visited array

void permute(vector<int>& ds, vector<int>& arr, 
             vector<vector<int>>& ans, bool visited[]) {
    if (ds.size() == arr.size()) {
        ans.push_back(ds);
        return;
    }
    
    for (int i = 0; i < arr.size(); i++) {
        if (!visited[i]) {
            visited[i] = true;
            ds.push_back(arr[i]);
            permute(ds, arr, ans, visited);
            ds.pop_back();
            visited[i] = false;
        }
    }
}

Approach 2: Swap method (Space Optimized)

void permute2(int ind, vector<int>& arr, vector<vector<int>>& ans) {
    if (ind == arr.size()) {
        ans.push_back(arr);
        return;
    }
    
    for (int i = ind; i < arr.size(); i++) {
        swap(arr[ind], arr[i]);
        permute2(ind + 1, arr, ans);
        swap(arr[ind], arr[i]); // Backtrack
    }
}
"Approach 2 is better — no extra space for visited array or ds. Just swap and recurse. This is what interviewers love to see!"
