What is Two Pointer?
The pattern that kills O(n²) and makes you look smart in interviews

Bhai, Two Pointer ek technique hai jisme hum ek hi array mein do index ek saath manage karte hain. Isko samajhna bahut zaroori hai kyunki yeh pattern bahut saare problems mein dikhta hai — palindrome, two sum, container with water, merge sorted arrays — sab mein!

The Core Idea

Imagine you have a sorted array and you want to find two numbers that add up to a target. The brute force way — check every pair — is O(n²). Two pointer cuts it down to O(n).

We place one pointer at the left (start) and one at the right (end). Based on the current sum vs target, we intelligently move one of them. This is the key insight — we never go backwards unnecessarily.

Build the Intuition
Why does moving the pointer work? Let's think before we code.

Sabse pehle socho — sorted array mein agar left + right > target hai, toh hum right ko decrease karein. Kyun? Kyunki left badhane se sum aur badhega! Yeh greedy decision hai — aur yahi Two Pointer ki jaan hai.

The "Book Shelf" Analogy

Imagine books arranged by weight on a shelf — lightest on left, heaviest on right. You want two books whose combined weight = exactly 10 kg.

You pick the lightest + heaviest. If it's too heavy → put back the heavy one, pick the next lighter. If it's too light → put back the light one, pick the next heavier. You never need to go backwards!

The Decision Rule (memorize this)

// For sorted array, two pointer decision logic:
int sum = arr[L] + arr[R];

if (sum == target)  → // FOUND! return {L, R}
if (sum < target)   → L++    // need bigger sum → move left forward
if (sum > target)   → R--    // need smaller sum → move right backward
Two Sum II
LeetCode #167 · Sorted array · Find pair with given target
MediumTwo Pointer

Problem Statement

Given a 1-indexed sorted array numbers, find two numbers that add up to target. Return their 1-based indices. Each input has exactly one solution. You may not use the same element twice.

Yeh problem Two Pointer ka seedha application hai. Array pehle se sorted hai — yeh humara cue hai ki opposite-end two pointer chalega. Ab step by step code likhte hain, pehle pseudocode, phir Java.

Step 1 — Pseudocode First (always!)

// Two Sum II — Pseudocode
L = 0, R = n-1

while L < R:
    sum = arr[L] + arr[R]
    if   sum == target → return {L+1, R+1}   // 1-indexed
    elif sum < target  → L++
    else               → R--

Step 2 — Java Code

public int[] twoSum(int[] numbers, int target) {
    int L = 0, R = numbers.length - 1;

    while (L < R) {
        int sum = numbers[L] + numbers[R];

        if (sum == target) {
            return new int[]{ L + 1, R + 1 };  // 1-indexed
        } else if (sum < target) {
            L++;   // need bigger sum
        } else {
            R--;   // need smaller sum
        }
    }
    return new int[]{ -1, -1 }; // guaranteed not reached
}

Valid Palindrome
LeetCode #125 · String from both ends · Classic two pointer
EasyTwo Pointer

Problem Statement

Given a string, check if it is a palindrome considering only alphanumeric characters and ignoring cases. E.g. "A man, a plan, a canal: Panama" → true

Yahan bhi same pattern — L from start, R from end. Agar L aur R dono alphanumeric nahi hain toh skip karo. Jab dono valid hain, compare karo. Agar match nahi hua → not palindrome. Loop karo jab tak L < R.

Java Code

public boolean isPalindrome(String s) {
    int L = 0, R = s.length() - 1;

    while (L < R) {
        // skip non-alphanumeric from left
        while (L < R && !Character.isLetterOrDigit(s.charAt(L))) L++;
        // skip non-alphanumeric from right
        while (L < R && !Character.isLetterOrDigit(s.charAt(R))) R--;

        if (Character.toLowerCase(s.charAt(L)) != 
            Character.toLowerCase(s.charAt(R))) {
            return false;
        }
        L++; R--;
    }
    return true;
}

Container with Most Water
LeetCode #11 · Greedy pointer movement · Medium classic
MediumTwo Pointer + Greedy

Problem Statement

Given n vertical lines at positions 0..n-1, line[i] has height h[i]. Find two lines that form a container holding the most water. Return the maximum area.

Yahan tricky part yeh hai — hum shorter wall wale pointer ko move karte hain. Kyun? Kyunki area = min(h[L], h[R]) × (R - L). Agar hum taller wall ko move karein, toh width toh kam ho hi rahi hai, aur height bhi nahi badh sakti shorter wall ki wajah se. So always move the shorter one!

The Greedy Key Insight

Area = min(height[L], height[R]) × (R - L)

Moving the taller pointer inward can only make things worse — width decreases AND the bottleneck (shorter height) doesn't change.
Moving the shorter pointer inward gives a chance to find a taller wall and increase area.

Java Code

public int maxArea(int[] height) {
    int L = 0, R = height.length - 1;
    int maxWater = 0;

    while (L < R) {
        int h   = Math.min(height[L], height[R]);
        int w   = R - L;
        int area = h * w;
        maxWater = Math.max(maxWater, area);

        // move the shorter wall — key greedy decision
        if (height[L] < height[R]) L++;
        else                             R--;
    }
    return maxWater;
}

The Mental Checklist

When you see a problem, ask these 3 questions in order:

1. Is the array sorted (or can I sort it)? → Opposite ends two pointer
2. Do I need to compare/modify in-place without extra space? → Slow/fast pointer
3. Do I need a subarray/substring of some condition? → Think Sliding Window (cousin of two pointer)

Two Pointer vs Sliding Window
