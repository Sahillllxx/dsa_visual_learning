02
Binary Number System
🎙
STRIVER SAYS

Bhaiya, hum decimal (base 10) mein sochte hain — 10 digits: 0–9. Computer binary (base 2) mein sochta hai — sirf 2 digits: 0 aur 1. Kyun? Circuit mein sirf do states hain — current ON = 1 ya current OFF = 0. Same positional system, different base!

DECIMAL — BASE 10
Number: 3 2 5
Position: 2  1  0
= 3×10² + 2×10¹ + 5×10⁰
= 300+20+5 = 325
BINARY — BASE 2
Number: 1 1 0 1
Position: 3  2  1  0
= 1×2³ + 1×2² + 0×2¹ + 1×2⁰
= 8+4+0+1 = 13
HOW 13 LIVES IN MEMORY — 8-BIT
= 8+4+1 = 13
Key Terms: 1 bit = one 0/1  |  8 bits = 1 byte  |  int = 32 bits  |  long long = 64 bits
MSB = Most Significant Bit (leftmost)  |  LSB = Least Significant Bit (rightmost)

🎙
STRIVER SAYS

2's Complement — How Negatives Live in Memory!
🎙
STRIVER SAYS

Bhaiya, yeh sabse important concept hai! Computer mein negative numbers ko 2's complement mein store karte hain. Formula: -n = ~n + 1! (1's complement + 1). Kaam karta hai kyunki n + (-n) = 0 hona chahiye — 2's complement exactly wahi guarantee karta hai!

Why 2's over 1's complement?
1's complement had TWO zeros: +0 (00000000) and -0 (11111111) — problematic!
2's complement has ONE zero. CPU addition works identically for positive and negative! 
int n = 13;
int neg = -n;           // CPU does ~n+1 internally!
int manual = ~n + 1;   // same result: -13
// Branchless abs:
int mask = n >> 31;      // 0 if +ve, -1 if -ve
int abs_n = (n ^ mask) - mask;

The 8 Must-Know Tricks
🎙
STRIVER SAYS

Bhaiya, yeh 8 tricks yaad kar lo! Amazon, Google, Microsoft — sab jagah poochhe jaate hain! Ab jab binary, sign bit, complements sab pata hai — in tricks ke WHY automatically samajh aayenge! Formula ratto mat — understand karo!

TRICK 01
Check ODD or EVEN
n & 1 == 1 → ODD
n & 1 == 0 → EVEN
Last bit of even = always 0, odd = always 1. AND with 1 isolates just LSB. Faster than n%2!
TRICK 02
Check if ith bit is SET
if (n & (1 << i))
1<<i = mask with only bit i = 1. AND with n: if bit i of n is 1 → non-zero = set!
TRICK 03
SET ith bit (→ 1)
n = n | (1 << i)
OR with mask having only bit i = 1. OR with 1 always gives 1. All other bits unchanged!
TRICK 04
CLEAR ith bit (→ 0)
n = n & ~(1 << i)
~(1<<i) = all 1s except bit i (1's complement!). AND forces bit i to 0, rest unchanged!
TRICK 05
TOGGLE ith bit (flip)
n = n ^ (1 << i)
XOR with 1 flips (0→1, 1→0). XOR with 0 keeps same. So XOR with mask flips only bit i!
TRICK 06
Remove Rightmost Set Bit
n = n & (n - 1)
n-1 flips all bits from rightmost 1 downward. AND removes that 1. Core of Brian Kernighan!
TRICK 07
Check Power of 2
n > 0 && (n & (n-1)) == 0
Powers of 2 have exactly ONE set bit. Remove it → becomes 0. If yes = power of 2!
TRICK 08
Multiply / Divide by 2^k
n << k → n × 2^k
n >> k → n ÷ 2^k
Left shift = append zeros (×2). Right shift = remove bits (÷2). Much faster than * or /!
🔑 Golden XOR Properties (MOST ASKED!):
n ^ n = 0  |  n ^ 0 = n  |  XOR is commutative & associative
[1,1,2,2,3] → 1^1^2^2^3 = 0^0^3 = 3 → find unique in O(n) time, O(1) space!

Dry Run — Count Set Bits (Brian Kernighan)
🎙
STRIVER SAYS

Bhaiya, classic problem — count 1s in binary of n. Naive: O(32). Brian Kernighan: runs only as many times as set bits! n=13 (three 1s) → only 3 iterations. Key: n & (n-1) removes rightmost set bit. Dekho step by step!

n = — count = 0
Press Next Step → to start! n = 13 (binary: 1101, has 3 set bits)
Step 0/6 
int countSetBits(int n) {
    int count = 0;
    while (n != 0) {
        n = n & (n - 1);  // removes rightmost set bit
        count++;
    }
    return count;   // runs exactly popcount(n) times!
}
// C++ shortcut: __builtin_popcount(n)
